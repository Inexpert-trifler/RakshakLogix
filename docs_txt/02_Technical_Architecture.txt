RakshakLogix — Technical Architecture

Backend source of truth

Locked Stack

Python + FastAPI — API/backend.

PostgreSQL + PostGIS — relational and geospatial database.

SQLAlchemy 2.x + Alembic — ORM and migrations.

Pydantic — request/response validation.

Pandas + NumPy + scikit-learn + XGBoost + Statsmodels — ML.

Google OR-Tools + NetworkX — optimization and graphs.

Redis + Celery — background jobs.

JWT + Argon2id/bcrypt — authentication.

Pytest + HTTPX — tests.

Docker + Docker Compose — reproducible environment.

Architecture

React client → FastAPI → service layer → ML/optimization → PostgreSQL/PostGIS. Redis/Celery handles long-running imports, forecasts, optimization and simulations. Weather/GIS providers sit behind integration adapters.

Repository Structure

app/main.py

app/core — config, database, security, logging

app/api/routes — HTTP endpoints

app/models — SQLAlchemy entities

app/schemas — Pydantic DTOs

app/services — business logic

app/ml — feature engineering, forecasting, risk

app/optimization — routing and vehicle optimization

app/integrations — weather/GIS adapters

app/workers — background jobs

tests / alembic / data / scripts

Service Boundaries

InventoryService — stock, transactions, safety stock and runway.

ForecastService — feature generation, model selection, forecasts and metrics.

RiskService — risk scoring, alerts and explanations.

RoutingService — network graph and route scoring.

OptimizationService — vehicle allocation and constrained routing.

SimulationService — scenario state, perturbations and comparisons.

ImportService — CSV validation and bulk ingestion.

DashboardService — aggregated frontend read models.

API Conventions

Base path: /api/v1

JSON contracts with OpenAPI.

UTC ISO-8601 timestamps.

UUIDs for exposed entity identifiers.

Pagination for collections.

Consistent errors: code, message, details, request_id.

Long-running operations return job_id and status.

Deployment

Local: Docker Compose with API, PostgreSQL/PostGIS and Redis.

Staging: sanitized synthetic/demo dataset.

Production/field deployment only after authorized security review.
